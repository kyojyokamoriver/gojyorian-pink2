ごじょリアンAR：GitHubアップロード用（フォルダなし・自動AR切替）

1. ZIPを解凍します。
2. GitHubの Add file → Upload files を開きます。
3. 解凍した中のファイルを全部選び、まとめてドラッグします。
   ZIP自体や外側のフォルダではなく、index.htmlなどの中身を入れてください。
4. Commit changesで保存します。
5. Settings → Pages → Sourceを Deploy from a branch にします。
   Branchはmain（または使用中のブランチ）、Folderは / (root) を選んでSaveします。

一度設定すれば次回からファイルを上書きするだけです。ビルド、APIキー、フォルダ作成、Actionsのpath変更は不要です。
以前のdistフォルダには入れず、リポジトリの一番上へアップしてください。
古い公開用Actionsがある場合は、Disable workflowで重複公開を防いでください。
各ZIPは独立したサイトです。複数色のファイルを同じ場所に混ぜないでください。

自動切替
・対応端末：Quick LookまたはWebXR。床に固定し、近づいたり周囲を歩いたりできます。「床に置く」の起動操作が必要です。
・非対応と判定した端末：自動で外カメラを開いて宇宙人を重ねる簡易AR。
・標準ARの準備やWebXRの起動が失敗した場合も簡易ARへ切り替えます。
・簡易AR：ドラッグで移動、2本指で拡大縮小・回転。「回す」で1本指の操作を回転に切替、「戻す」で位置・大きさ・向きをリセット。
・簡易ARの上部の「簡易AR」表示は削除済みです。
・内カメは最大3人。瞬き、粒子演出、写真保存・共有に対応。
・簡易ARも瞬き、粒子演出、柔らかい影、写真保存・共有に対応。

簡易ARは画面内に配置します。床認識、実際の歩行や距離の追跡はしません。
カメラ使用の許可とHTTPSが必要です。カメラを利用できないブラウザ等では簡易ARも起動できません。
iOS標準AR画面が開いた後の状態はサイトから取得できず、対応判定が通っても床認識を保証するものではありません。
iPhone標準AR画面はタップで写真・シャッター長押しで動画。簡易AR・内カメ・WebXRの動画録画は未実装です。
標準AR画面の「AR／オブジェクト」等の操作部はiOSの機能です。

検証：自動判定、起動失敗時の切替、カメラの解放と切替、簡易ARの操作・写真合成処理を模擬環境で確認。スマホ実機での確認は別途必要です。
